# Blog Fullstack App

## Tech Stack

### Backend
- ASP.NET Core Web API
- Entity Framework Core
- PostgreSQL

### Frontend
- React (Vite)
- Axios

## Features

- Create Post
- Get Posts
- Update Post
- Delete Post

## Architecture

Controller → Service → EF Core → PostgreSQL

## Setup

### Backend
cd blogapi
dotnet run

### Frontend
cd blog-client
npm install
npm run dev
